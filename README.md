# 📚 Student Performance Analysis

An exploratory data analysis (EDA) project that uncovers patterns and relationships in student academic performance using math, reading, and writing scores.

---

## 📌 Overview

This project analyzes a student performance dataset to understand how different factors affect academic scores. It uses visualizations like correlation heatmaps and scatter plots to reveal insights from the data.

---

## 🛠️ Tech Stack

| Tool | Purpose |
|------|---------|
| Python | Core language |
| Pandas | Data loading and manipulation |
| Matplotlib | Plotting and visualizations |
| Seaborn | Statistical visualizations |
| Jupyter Notebook | Development environment |

## 📊 Analysis Highlights

### 🔥 Correlation Heatmap
Shows the correlation between math, reading, and writing scores — revealing how strongly these subjects are related to each other.

### 📈 Scatter Plot — Math vs Reading Score
Visualizes the relationship between math and reading scores across all students, showing performance trends and outliers.

---

## 📂 Dataset

- **Source:** [Students Performance in Exams – Kaggle](https://www.kaggle.com/datasets/spscientist/students-performance-in-exams)
- **Features:** Gender, race/ethnicity, parental education, lunch type, test preparation, math/reading/writing scores

---

## 💡 Key Insights

- Reading and writing scores show a strong positive correlation
- Students who completed test preparation tend to score higher across all subjects
- Math scores show slightly more variance compared to reading and writing
